Task-shaped walkthroughs. Each one takes a single job — get a first suite running, stop
mocks returning `&#123;&#125;`, make a load run mean something — and follows it from the
smallest working command to the version you would put in CI, with the failure modes named
along the way.

The reference pages describe *what the tool does*. These describe *what you do*.
